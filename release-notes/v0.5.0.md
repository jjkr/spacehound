## Highlights

SpaceHound now works inside Mission Control and App Exposé. While either
overlay is showing, the window-focus hotkeys (⌥Tab / ⌥⇧Tab by default) step
the blue hover highlight through the visible thumbnails in reading order, the
display hotkeys move the highlight to the frontmost thumbnail on the target
display, and inside Mission Control the Space hotkeys highlight the frontmost
window of the Space they switch to. Opening an overlay with a SpaceHound hotkey
highlights the focused window right away, and dismissing it through SpaceHound
brings the highlighted window to the front with no extra click or animation.

Crash reporting is now opt-in. On the first launch after updating, SpaceHound
asks whether it may send crash reports; nothing is sent until you accept. You
can change the answer at any time with **Send crash reports** in
**Settings › Advanced**.

SpaceHound is now open source under the Apache License 2.0.

## Improvements

- Switching to a display with windows brings its frontmost window forward
  through the window server before any accessibility lookup, saving tens of
  milliseconds per switch.
- Switching to an empty display clicks the middle of its menu bar directly
  instead of probing it first.
- Hotkey actions no longer re-check Accessibility permission on every press.
- In App Exposé, the display hotkeys skip displays the app has no windows on.
- The menu bar Space number keeps a fixed width across Spaces with the same
  number of digits, so neighbouring menu bar items no longer shift when you
  switch.
- If the runtime fails to start, the menu bar shows a ⚠️ badge and the menu
  names the error. The **Space _X_ of _Y_** menu item is gone; the Space number
  in the menu bar already shows it.
- Settings gains an **Advanced** section holding **Receive beta updates**,
  **Send crash reports**, **Switch workspaces on the focused display**, and
  **Move cursor to the target display**.
- The Settings window now has **OK**, **Apply**, and **Cancel** buttons, shows
  **Unsaved changes** while edits differ from disk, and asks before closing,
  reloading, or quitting with unsaved edits.
- Holding Option while opening the menu bar menu reveals
  **Test Crash Reporting…**, which crashes the app on purpose (after
  confirmation) so the crash-report pipeline can be verified.
- The app bundle includes the license, notice, and third-party notices.

## Fixes

- **Grant Accessibility Access…** now re-registers SpaceHound in the
  Accessibility list before opening System Settings. Previously, if the entry
  had been removed or macOS had stopped recognising the app, the list opened
  without SpaceHound in it and there was nothing to enable.
- Switching away from the Space holding the Settings window and back left the
  window behind other apps' windows. It now returns to the front like any
  other app's window.
- Quitting with unsaved settings edits no longer stops hotkeys before the
  save prompt, so cancelling the quit leaves SpaceHound working.
