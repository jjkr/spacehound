## Highlights

SpaceHound can now launch automatically when you sign in. Enable **Launch at
login** in Settings; macOS will guide you through approval if needed.

## Improvements

- SpaceHound no longer requires Input Monitoring permission.
- Update delivery is monitored so feed and download failures can be detected
  sooner.
- Privacy-limited crash reporting now helps diagnose failures without sending
  settings, user identity, screenshots, logs, analytics, performance traces, or
  network activity.
